# 週次 X 投稿テンプレ

週 1 回、固定曜日に投稿する。宣伝トーンにせず「こういう問題が挙がっている」の共有に徹する。

## 基本形

```
今週の未解決問題

1. <問題タイトル> <issue URL>
2. <問題タイトル> <issue URL>
3. <問題タイトル> <issue URL>

解けそうなものがあれば issue にコメントで。
```

## 解決報告があった週

解決を先頭に持ってくる。これが一番の宣伝になるので、新着問題より優先する。

```
先週の「<問題タイトル>」が解決されました。解決までの経緯は issue に残っています。
<issue URL>

今週の未解決問題
1. ...
```

## 注意

- ハッシュタグは付けても 1 個まで
- 「ぜひ」「お気軽に」のような勧誘の言葉は使わない
- 閲覧数や登録者数のような運営側の数字は書かない
- 投稿は週 1 回で固定。問題が少ない週は 1 問でも成立させる (水増ししない)
