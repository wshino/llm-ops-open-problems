# X 投稿テンプレ

リポジトリの宣伝や digest 形式にしない。自分の悩みとして書く。「今週の未解決問題」のようなまとめ体裁は個人アカウントから出すと宣伝に見えるのでやらない。語り口は普段の自分のポストに合わせる。

## 基本形 (1 投稿 1 問題)

最近困っていることを自分の言葉で 2〜3 文。締めに issue の URL を置くだけ。呼びかけはしない。

```
<最近これで困ってる、を自分の言葉で>
issue 立てたので知見ある人いたら
<issue URL>
```

例:

```
agent を 3〜4 個並走させてると、どれかが入力待ちで止まってるのに気づかず 1 時間経ってた、が何度も起きてる。完了通知の一元監視ってみんなどうしてるんだろう。issue 立てたので知見ある人いたら
https://github.com/wshino/llm-ops-open-problems/issues/1
```

## 解決したとき

```
前に投げた「<問題>」、<こういう方法> で解決した。経緯は issue に残ってます
<issue URL>
```

## 注意

- 「ぜひ」「お気軽に」「解けそうなものがあれば」のような呼びかけの言葉は入れない
- ハッシュタグは付けない
- ペースは週 1 問くらい。まとめて数問流さない
- リポジトリ自体の紹介投稿はしない。問題が主役
