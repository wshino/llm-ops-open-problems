# [problem] upstream の CLI 更新のたびにローカルパッチの再適用が必要

## 困っていること

上流の CLI ツールに自分用のパッチ (ローカルモデル対応の差し替えなど) を当てて使っていると、ツールの update のたびにパッチが吹き飛び、手で再適用が必要になります。再適用を忘れて「なぜか動かない」で時間を溶かすのを繰り返しています。AI 系 CLI はリリース頻度が高いので、この維持コストが無視できません。

## 環境

- macOS、Homebrew / npm / bun でインストールした CLI 群
- パッチ対象は node 製 CLI のバンドル済み JS など

## 試したこと

- fork して rebase で追従。リリース頻度が高いと追従自体が仕事になる
- パッチファイル + 適用スクリプトを用意して、気づいたときに手動実行

## どんな解決なら嬉しいか

update を検知してパッチ適用まで自動で走らせる運用パターン。package manager の hook に挟む定石や、そもそもパッチ運用を避ける設計 (wrapper で外から差し替える等) の事例でも嬉しいです。
