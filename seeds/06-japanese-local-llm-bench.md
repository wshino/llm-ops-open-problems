# [problem] 日本語タスクに特化したローカル LLM の品質ベンチが存在しない

## 困っていること

ローカル LLM を日本語の翻訳や文章生成に使いたいのですが、公開ベンチマークのほとんどが英語タスクの流用で、日本語の実用品質 (敬語の自然さ、翻訳の正確さ、長文要約の破綻しにくさ) を比較できる材料がありません。ユーザー向けの文言など出荷物に使えるかどうかの判断がモデルごとに勘と目視頼みになっています。

## 環境

- Mac Studio 上の量子化モデル各種 (GLM 系、Kimi 系、日本語特化の小型モデル等)

## 試したこと

- 手元の数十例で目視比較。再現性がなく、モデルの update のたびにやり直しになる
- 英語ベンチのスコアを参考にする。日本語の敬語や語順の品質とほぼ相関しない印象

## どんな解決なら嬉しいか

日本語運用に特化した軽量ベンチ。まずは翻訳、敬語を含むビジネス文、長文要約の 3 タスクだけでも、ローカルで再現実行できる形の比較データがあると助かります。既にやっている方がいれば手法だけでも知りたいです。
